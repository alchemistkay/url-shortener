# Contributing Guidelines

## Overview

This is a portfolio project demonstrating production-grade DevOps practices. While not actively seeking external contributions, the codebase is open for educational purposes.

## Using This Project as Reference

You are welcome to:
- Study the code and architecture
- Fork for learning purposes
- Reference in your own projects
- Share as an educational resource

## Reporting Issues

If you find bugs or security vulnerabilities:
1. Open a GitHub issue with detailed description
2. For security issues, email directly (see README)

## Code of Conduct

Be respectful and constructive in all interactions.

## Questions

For questions about the implementation or architecture decisions, feel free to open a discussion in GitHub Issues.
